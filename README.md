# Al-Style
Модуль синхронизации сайта на CMS Битрикс и al-style.kz по API.

Данный модуль позволяет импортировать новые товары на сайт с установленной CMS Битрикс с сайта al-style.kz по API, а также обновлять цены и остатки товаров у уже импортированных товаров.

Порядок работы с модулем:
1) загеристрироваться на сайте https://b2bportal.al-style.kz/site/login для получения токена доступа.
2) скачать архив с модулем или склонировать репозиторий командой git clone https://github.com/Andersen92/Al-Style.git
3) скопировать папку модуля itl.alstyle в директорию /bitrix/modules/
4) в админке сайтв в разделе Marketplace - Установленные решения установить появившийся модуль Модуль синхронизации БУС и al-style.kz по API (itl.alstyle)
5) в админке сайта перейти в раздел Настройки - Настройки продукта - Настройки модулей и выбрать данный модуль в выпадающем списке и в поле Access Token указать полученный токен доступа.
6) поставить на крон скрипт /bitrix/php_interface/include/catalog_import/alstyle_run.php с нужной периодичностью
